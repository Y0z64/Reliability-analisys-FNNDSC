# Reliability analysis — fetal subplate segmentation (FNNDSC)

Measures how reproducible a fetal brain **subplate** segmentation model is when the
same scan is reconstructed four times from different slice subsets (`S1`–`S4`).
Reliability is quantified on SP volume, WM surface area, SP thickness and
segmentation overlap, and modelled against gestational age, image QA, stack count,
SNR and CNR.

Replicates a prior lab study that did the same for the cortical plate model
(`assets/reliability_paper.pdf`).

## Quickstart

The analysis notebooks read only `data/*.csv`, which is tracked here — so this
reproduces the paper tables without cluster access:

```bash
uv sync
cd src
uv run jupyter lab      # run paper_models.ipynb, then bootstrap_covariates.ipynb
```

Regenerating the CSVs themselves needs FNNDSC cluster access — see
[`docs/pipeline.md`](docs/pipeline.md).

## Layout

```
data/          input + derived CSVs (tracked; subject.csv and
               raw_subject_data.csv are hand-curated and irreplaceable)
assets/        result tables — the numbers behind the paper — and the
               reference-paper PDFs
  artifacts/   generated figures (gitignored; regenerated by the notebooks)
src/
  paper_models*.ipynb, bootstrap_covariates.ipynb   current analysis
  image_quality_metrics.py    SNR/CNR/volume metrics (CLI)
  slides_helpers.py           regression fitting + result tables
  processing/                 cluster-side: prediction, surfaces, audits
  reliability/                per-subject Dice/Jaccard reports
  functions/                  shared image ops + boundary CNR
  surface_analysis/           surface and thickness notebooks
  multivariate_analysis/, cnr_analisys/, summary_analisys/   legacy
reference/     FreeSurferColorLUT.txt
archive/       dead code, kept for traceability (see archive/README.md)
reports/       per-subject PDFs (generated, gitignored)
```
